# 🚛 LogiFlow — Логистический ИИ-ассистент

Веб-приложение для приёма, классификации и управления заявками на перевозку грузов с голосовым вводом, двумя ИИ-агентами, RAG и ML-моделью.

---

## 📁 Структура проекта

```
logiflow/
├── app.py                  # Streamlit-интерфейс
├── logistics_agent.py      # Вся логика: агенты, ML, RAG, инструменты
├── requirements.txt
├── key.env                 # GigaChat API ключ
├── salut.env               # Salute Speech токен
└── files/
    ├── orders.csv          # База заявок (создаётся автоматически)
    ├── cargo_rules.txt     # Правила перевозки (опционально)
    ├── tariffs.txt         # Тарифы (опционально)
    └── perevozki.pdf       # Законодательная база (опционально)
```

---

## ⚙️ Установка и запуск

### 1. Создать папку проекта и скопировать файлы

```bash
mkdir logiflow
cd logiflow
# скопируйте app.py, logistics_agent.py, requirements.txt сюда
mkdir files
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Создать файлы с ключами

**key.env** (GigaChat):
```
GIGACHAT_API_KEY=ваш_ключ_gigachat_base64
```
Получить ключ: https://developers.sber.ru/portal/products/gigachat

**salut.env** (Salute Speech — для голоса):
```
SALUT=ваш_basic_токен_salute_speech
```
Получить токен: https://developers.sber.ru/portal/products/smartspeech
> ⚠️ Если голос не нужен — создайте файл с пустым значением `SALUT=`, приложение запустится без голосового ввода/вывода.

### 4. (Опционально) Добавить документы в базу знаний

Положите в папку `files/` любые из:
- `perevozki.pdf` — ФЗ о перевозках
- `cargo_rules.txt` — правила перевозки грузов
- `tariffs.txt` — тарифная сетка
- `routes.txt` — информация о маршрутах

Если файлы не добавить — используется встроенная база знаний.

### 5. Запустить приложение

```bash
streamlit run app.py
```

Откроется браузер: **http://localhost:8501**

---

## 📋 Соответствие требованиям

| Требование | Реализация |
|---|---|
| Веб-приложение | Streamlit |
| Элементы управления | Кнопки, поля ввода, фильтры, выпадающие меню |
| Ввод и генерация текста | Текстовые заявки + ответы агентов |
| Дополнительная модальность | Распознавание и синтез речи (Salute Speech) |
| Внешние данные | CSV (заявки), TXT/PDF (правила перевозок) |
| LangChain + контекстное окно | ConversationBufferMemory для каждого агента |
| Минимум 2 цепочки | chain1 (RAG-ответ) + chain2 (суммаризация) в `consult_logistics_rules` |
| RAG | BM25Retriever по базе знаний о перевозках |
| Минимум 2 агента | `dispatcher_executor` + `analyst_executor` |
| ML-модель | RandomForestClassifier: предсказание приоритета заявки |

## 🚛 Как пользоваться

### Вкладка «Приём заявок»
- Введите описание перевозки: *«500 кг яблок из Твери в Москву к пятнице»*
- Или загрузите WAV-файл с голосовой заявкой (16кГц, моно)
- ИИ-диспетчер распарсит заявку, определит приоритет и тип транспорта через ML
- Заявка сохранится в таблицу, будет озвучен голосовой ответ

### Вкладка «Таблица заявок»
- Просмотр всех заявок с фильтрацией
- Скачивание в CSV

### Вкладка «Консультация»
- Задайте вопрос о правилах, тарифах, документах
- ИИ-аналитик найдёт ответ в базе знаний через RAG
